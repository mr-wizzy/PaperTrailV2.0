# PaperTrail — Clinical Research Dashboard (Web App)

This directory contains the Vite + React + TypeScript source code for the **PaperTrail** Clinical Research Dashboard.

For comprehensive architectural documentation, design specifications, and 5-screen investigative workflows, refer to the root [README.md](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run production build (typecheck + bundle)
npm run build
```
